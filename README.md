🚀 Mini NPU Simulator
본 프로젝트는 AI 가속기인 **NPU(Neural Processing Unit)**의 핵심 동작 원리인 MAC(Multiply-Accumulate) 연산을 소프트웨어로 시뮬레이션하는 학습용 프로젝트입니다.

📌 프로젝트 개요
입력된 패턴(이미지 데이터)과 미리 정의된 필터(가중치)를 비교하여, 어떤 패턴에 더 가까운지 판정합니다. 실제 AI 모델이 이미지를 분류하는 기초적인 원리를 체험할 수 있도록 설계되었습니다.

✨ 주요 기능
사용자 입력 모드 (3x3): 사용자가 직접 0과 1로 구성된 행렬을 입력하여 즉시 결과를 확인합니다.
JSON 분석 모드: data.json에 정의된 테스트 케이스를 불러와 대량의 데이터를 자동 분석하고 PASS/FAIL 여부를 판정합니다.
성능 측정: 연산 시간을 ms 단위로 측정하고, 행렬 크기에 따른 연산 횟수를 계산합니다.
라벨 정규화: 입력 데이터의 공백이나 대소문자 차이를 자동으로 보정하여 판정 정확도를 높였습니다.

⚙️ 핵심 기술 사양
1. MAC (Multiply-Accumulate) 연산
AI 연산의 90% 이상을 차지하는 곱셈-누산 연산을 구현하였습니다.

공식: $Score = \sum_{i=1}^{n} (Input_i \times Filter_i)$
두 행렬의 각 원소를 곱하고 모두 더해 패턴의 유사도를 점수화합니다.
2. 수치 안정성 (Epsilon 정책)
부동소수점 연산 시 발생하는 미세한 오차를 해결하기 위해 허용 오차(epsilon) 기반의 비교 로직을 적용했습니다.

abs(prediction_score - expected_score) < 1e-9
3. 시간 복잡도 분석
행렬의 크기가 $N \times N$일 때, 전체 연산 횟수는 $N^2$에 비례합니다.

Complexity: $O(N^2)$
데이터 크기 증가에 따른 성능 변화를 로그를 통해 확인할 수 있습니다.

# 분석 결과를 담을 리스트가 있다고 가정 (예: results = [{"name": "Case1", "result": "PASS", "reason": ""}, ...])

def print_final_summary(results):
    total = len(results)
    passed = sum(1 for r in results if r["result"] == "PASS")
    failed = total - passed
    
    print("\n" + "="*50)
    print("           📊 MINI NPU TEST SUMMARY")
    print("="*50)
    print(f" ✅ 전체 테스트 케이스 : {total:>3} 개")
    print(f" ✨ 통과(PASS)        : {passed:>3} 개")
    print(f" ❌ 실패(FAIL)        : {failed:>3} 개")
    print(f" 📈 최종 합격률       : {(passed/total)*100:>5.1f}%")
    print("-"*50)

    if failed > 0:
        print(" [ 실패 케이스 목록 ]")
        for idx, r in enumerate(results):
            if r["result"] == "FAIL":
                print(f"  - {idx+1}. {r['name']}: {r['reason']}")
    else:
        print(" 🎉 축하합니다! 모든 테스트를 통과했습니다.")
    
    print("="*50 + "\n")

# >> 실패 원인 분석 및 해결 (Failure Analysis)
테스트 과정에서 발생한 실패(FAIL) 케이스를 세 가지 유형으로 분류하고 진단하였습니다.

분류	발생 원인 (Root Cause)	해결 방법 (Resolution)
라벨/스키마 문제	JSON 내 expected 라벨의 대소문자 불일치(cross vs Cross) 또는 앞뒤 공백 포함.	strip()으로 공백을 제거하고 capitalize() 또는 upper()를 사용하여 라벨을 표준화(Normalization)함.
부동소수점 오차	MAC 연산 과정에서 누적된 미세한 소수점 오차로 인해 prediction == expected 비교 시 False 발생.	직접 비교 대신 허용 오차(epsilon = 1e-9)를 설정하여 abs(A - B) < epsilon 방식으로 비교 정책 변경.
데이터 구조 문제	JSON 파일에 필수 키(pattern, expected)가 누락되어 KeyError 발생.	데이터 로드 단계에서 dict.get()을 활용하거나 예외 처리(try-except)를 통해 스키마 검증 로직 추가.

# >> 시간 복잡도 분석 (Time Complexity Analysis)
NPU 시뮬레이터의 핵심인 MAC 연산의 효율성을 수학적으로 분석합니다.

분석 대상: $N \times N$ 크기의 행렬 연산
연산 횟수: 입력 패턴의 모든 원소($N^2$개)에 대해 곱셈과 덧셈이 각각 1회씩 발생합니다.
예: $3 \times 3$ 패턴 = 9회 연산
예: $5 \times 5$ 패턴 = 25회 연산
시간 복잡도: $O(N^2)$
패턴의 가로/세로 크기($N$)가 커질수록 연산량은 제곱에 비례하여 증가합니다.
실제 측정 결과, 3x3 연산은 약 0.002ms 내외로 처리되었으나, 데이터 크기가 커질수록 NPU 가속기(하드웨어)의 병렬 처리 필요성이 증대됨을 확인하였습니다.

# >> 비교 정책의 중요성 (Comparison Policy)
단순한 값의 일치 여부를 확인하는 것을 넘어, AI 시스템에서는 다음과 같은 **비교 정책(Policy)**이 필수적임을 학습하였습니다.

수치적 정책: 하드웨어마다 다른 부동소수점 정밀도를 고려하여 epsilon 기반의 유연한 비교를 수행해야 합니다.
문자열 정책: 사용자 입력이나 외부 데이터(JSON)는 항상 불완전할 수 있음을 가정하고, 비교 전 반드시 정규화(Normalization) 과정을 거쳐야 시스템의 신뢰성(Reliability)을 보장할 수 있습니다.
